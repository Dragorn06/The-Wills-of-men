# The Wills of Men
A text adventure game. To play run the  ```main.py``` file with the requirements listed below installed. 

## Requirements

- python 3.8 and above reccommended 

- pygame 2.1.2
 
## instructions
The game has several buttons which can be pressed:

* go [direction] - sends you in the specified direction either north, south, east or west

* get [item] - picks up an item and places it in your inventory

* use [item] - uses the specified item

* talk [character] - talks to the specified Character

* examine [item] - examines an item in the players inventory

* save - saves your progress

* quit - quits the game (This will save your progress)

Any button shown above with a word in square brackets after it when pressed will prompt the player for the argument to use in the action.
