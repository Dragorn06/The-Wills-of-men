# The Wills of Men
A text adventure game I am developing. 

[![Pylint](https://github.com/Dragorn06/The-Wills-of-men/actions/workflows/pylint.yml/badge.svg)](https://github.com/Dragorn06/The-Wills-of-men/actions/workflows/pylint.yml)

## instructions
The game takes text inputs based on certain key words.

* go [direction] - sends you in the specified direction either north, south, east or west

* get [item] - picks up an item and places it in your inventory

* use [item] - uses the specified item

* talk [character] - talks to the specified Character

* explore - makes you search the room you arfe in and find secrets! 

* save - saves your progress

* quit - quits the game (This will save your progress)
